# China Candidate Channel Framework Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a provenance-first candidate channel pool, manual China testing record, classification profiles, and a strict read-only candidate checker without changing any published playlist bytes.

**Architecture:** A separate versioned candidates document stores only reviewed official page/HLS pairs and is parsed by a strict standard-library module. Catalog top-level profiles classify formal channels, while every M3U generator continues to read only the catalog. The candidate CLI adapts validated records into the existing `Channel` model and calls the existing `validate_channel` and Markdown reporting implementation.

**Tech Stack:** Python 3.12 standard library, JSON, Extended M3U, Markdown, `unittest`, GitHub Actions.
